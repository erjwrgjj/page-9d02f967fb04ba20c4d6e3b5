使用说明GETTING STARTED

第一次用别紧张，四步就能跑起来。照着做，卡住了再回头看哪一步漏了：

  1. 01
    选套餐、开通账号
    先确定自己大概每月用多少流量、几台设备要同时在线，再对应上面的套餐下单，避免重复换档。
  2. 02
    拿到订阅链接
    开通后会得到一条专属订阅链接，相当于你的“通行证”，别发给别人，分享会占用你的设备名额。
  3. 03
    导入客户端
    在客户端里选择“导入订阅 / 更新配置”，粘贴链接后拉取节点列表，完成一次更新就配置好了。
  4. 04
    挑节点、测延迟
    先全量测一次延迟，选响应快的节点连上；之后定期更新订阅，就能拿到最新的节点信息。

日常使用小建议

流量快到上限时可以升级到更高档位；设备数不够用也一样，换档比重新开号更省事。节点感觉变慢了，先更新订阅、换个节点试试，多数时候问题就解决了。

客户端CLIENTS

Precision 采用通用订阅格式，市面上的主流客户端大多可以直接导入使用。选哪个主要看你手头的设备习惯：

桌面端

Windows 与 macOS 上选择支持订阅导入的通用客户端即可，导入你的订阅链接后按需更新节点列表。旗舰版、团队版的用户建议开启客户端内的延迟测试功能，优先连接响应更快的节点。

移动端

iOS 与 Android 各有多种支持订阅格式的客户端可选。安装后在配置页粘贴订阅链接，完成首次更新即可使用。注意同一账号的同时在线设备数以套餐档位为准，超出的设备会无法连接。

路由器与其他设备

团队版支持企业定制路由，方便把整间办公室的设备统一接入；具体路由方案可在开通后通过客户经理沟通配置。

常见问题FAQ

关于套餐

三个套餐该怎么选？
看两个数：每月流量和同时在线设备数。一个人轻度使用，基础版的 100GB 足够；经常看流媒体或打游戏，旗舰版的 300GB 加 IPLC 游戏加速更合适；三五人以上的小团队一起用，直接选团队版，20 台设备名额和专属高带宽节点都更宽裕。
按月付和按年付差多少？
按年付相当于每月花十个月的钱用十二个月：基础版年付 ¥150、旗舰版年付 ¥350、团队版年付 ¥850。确定长期用的话，年付明显更划算。
流量用完了怎么办？
可以先升级到更高档位的套餐，流量和设备数都会随之提升。建议先在控制面板看一下用量趋势，再决定换到哪一档，避免反复调整。

关于使用

订阅链接怎么用？
复制订阅链接后，在客户端的“订阅管理”或“导入配置”里粘贴并保存，然后手动更新一次节点列表。之后客户端一般会自动定期更新；如果发现节点失效，先手动更新订阅试试。
设备数超了会怎样？
同一时间在线的设备数不能超过套餐上限，例如基础版是 3 台。超出的设备会连接不上，先在其他设备上退出连接，把名额空出来即可。
节点变慢了怎么办？
先更新订阅获取最新节点，然后测一次延迟，换到响应更快的节点。旗舰版用户可以优先选择 IPLC 专线节点获得更稳定的体验；还是不行的话，提交工单让支持同学帮你看。

关于服务

遇到问题找谁？
提交工单是最稳妥的方式。旗舰版享有 7x24 优先工单支持，团队版还有专属客户经理一对一对接；基础版同样可以通过工单获得帮助，只是响应按普通优先级排队。
团队版可以定制哪些内容？
团队版支持企业定制路由与专属高带宽节点，适合需要统一接入、固定线路方案的小团队或工作室。开通后可以和客户经理沟通具体的路由与节点需求。
